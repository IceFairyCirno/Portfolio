# IceFairyCirno — Personal Portfolio

Arctic-themed personal website for **Dicky Ling** (IceFairyCirno) — Year 4 CS student at HKU, mobile & indie game developer.

**Live site:** [https://icefairycirno.github.io/Portfolio/](https://icefairycirno.github.io/Portfolio/)

## Features

- Responsive single-page layout (Home, Vision, Projects, Education & Experience, Contact)
- Project highlights: LogFit, GForm, The Island (Unity), Touhou clone, Discord bot
- Canvas snowfall ambience with `prefers-reduced-motion` support
- Contact form via Formspree (AJAX, success/error feedback)
- SEO basics: meta description + Open Graph tags

## Tech Stack

| Layer | Choice |
|--------|--------|
| Markup | HTML5 |
| Styles | CSS3 (custom properties, grid, glassmorphism) |
| Logic | Vanilla JavaScript |

No build step or framework required.
